# DailyTracker

A lightweight daily task management web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Add daily tasks with priority and optional time
- Mark tasks as completed or pending
- Filter by all, pending, or completed
- Sort by newest, priority, or time
- Daily completion percentage and task statistics
- Clear all completed tasks
- Light/dark theme toggle
- Data persists in browser `localStorage`
- Responsive design for desktop and mobile

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Files

- `index.html` — application structure
- `styles.css` — responsive UI and theme styles
- `app.js` — task management and local persistence
