# 🚀 DailyTracker

> **Plan smarter. Prioritize better. Get things done.** ✅

DailyTracker is a modern, lightweight **daily task management and productivity dashboard** built with **HTML, CSS, and vanilla JavaScript**. It helps you organize work, personal activities, learning, and health goals from one clean interface — without a backend or account setup.

## ✨ Why DailyTracker?

DailyTracker is designed for people who want a simple but powerful way to manage everyday work. Add detailed tasks, set priorities and due dates, track progress, identify overdue work, maintain productivity streaks, and back up your data whenever you need it.

## 🌟 Key Features

### 📝 Smart Task Management
- ➕ Create tasks with title, priority, category, due date, time, and notes
- ✏️ Edit task titles and notes
- ✅ Mark tasks as completed or pending
- 🗑️ Delete individual tasks
- 🧹 Clear all completed tasks

### 🎯 Organization & Priorities
- 🔴 **High**, 🟡 **Medium**, and 🟢 **Low** priority levels
- 🏷️ Categories: Work, Personal, Learning, Health, and Other
- 📅 Due-date tracking
- ⏰ Optional task time
- ⚠️ Automatic overdue task detection

### 🔎 Powerful Task Discovery
- 🔍 Search across task titles, categories, and notes
- 📌 Filter by **All / Pending / Completed / Overdue**
- ↕️ Sort by **Newest / Priority / Time / Due Date**

### 📊 Productivity Dashboard
- 📋 Total task count
- ✅ Completed task count
- ⏳ Pending task count
- 🔥 High-priority task count
- 📈 Daily completion percentage
- 🔥 Productivity streak tracking
- 💡 Smart productivity insights

### 💾 Data & Backup
- 🔒 Tasks are stored locally in your browser using `localStorage`
- 📤 Export all tasks as a JSON backup
- 📥 Import a previous JSON backup
- 🌙 Dark mode with saved theme preference

### 📱 User Experience
- 📱 Responsive desktop, tablet, and mobile layout
- ⚡ No framework or build process required
- 🎨 Clean modern dashboard UI
- ♿ Semantic HTML and accessible labels for controls

## 🚀 Run Locally

No installation or build step is required.

1. Clone the repository.
2. Open `index.html` directly in your browser, **or** serve the folder using any static HTTP server.
3. Start adding your daily tasks. 🎯

## 🔐 Privacy

DailyTracker does not require an account or send your tasks to a server. Your task data is kept in the browser's local storage. Use the **Export** feature to create your own backup before clearing browser data.

## 💡 Example Workflow

**Morning ☀️** → Add today's important tasks → Set priorities → Add due times

**During the day 🚀** → Complete tasks → Review pending/overdue work → Search when needed

**Evening 🌙** → Check completion percentage → Review your streak → Clear completed tasks
